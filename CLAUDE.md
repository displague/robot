# Robot repo: start here

A home-printable, fishing-line tendon humanoid, so far entirely in simulation. `README.md` has the design
and the repository map.

Skills for working in this repo live in `.claude/skills/` and must be kept current: when you create or
learn a tool, generator or workflow, add or update its skill in the same commit.

| Skill | Use for |
| --- | --- |
| `.claude/skills/project-loop/SKILL.md` | prompt log, commits, decisions, branches, sibling repo, Agent Hub: read first |
| `.claude/skills/cad-generators/SKILL.md` | the Blender generators in `cad/blender` (STLs, presets, renders) |
| `.claude/skills/tendon-sim/SKILL.md` | the MuJoCo tendon model, gauntlet, recordings, teacher data |
| `.claude/skills/release/SKILL.md` | tags and GitHub releases with visuals and assets |
